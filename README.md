# DesenvolvimentoInterfaces
 
Este repositório guarda os projetos feitos em sala de aula da disciplina de Desenvolvimento de Interfaces do curso de Análise e Desenvolvimento de Sistemas.
 
## Conteúdo
 
Cada atividade desenvolvida durante as aulas fica em sua própria pasta, com os arquivos necessários para visualizar o resultado.
 
## Como visualizar
 
Para abrir um projeto, entre na pasta correspondente e abra o arquivo `index.html` no navegador.
